# Data contracts and public dataset integration

## GPS receiver CSV

Required numeric columns:

```text
PRN,DO,PD,RX,TOW,CP,EC,LC,PC,PIP,PQP,TCD,CN0
```

Training also needs `label` or `Output`. Numeric labels are preserved as strings; the system does not infer which spoofing subtype a number means. The optional `group` column must represent a real recording session, receiver, or independent capture unit. Do not manufacture unique row IDs and call them capture groups.

Validation rejects missing features, nonnumeric/nonfinite values, fewer than two or more than twenty classes, fewer than ten rows per class, empty groups, and exact duplicate feature rows. Missing values must be addressed explicitly before import. Both training and inference use the same ordered feature names.

From the original Mendeley spreadsheet, export the labeled sheet to CSV in Excel, or install `.[excel]` and use pandas `read_excel(...).to_csv(..., index=False)`. Confirm the sheet and label encoding with the original documentation. The original notebook uses `data3`.

Normal-reference anomaly detection currently recognizes `authentic`, `clean`, `0`, or `0.0`. Remap normal labels if your dataset uses another encoding. Features such as receiver time can leak campaign identity despite a random split: use true session groups and inspect feature ablations.

## Raw complex IQ

Signal Lab accepts a CSV with one sample per row:

```csv
I,Q
0.15,-0.02
-0.04,0.11
```

At least 256 samples are required. Sample rate is supplied separately in hertz. Values represent complex baseband samples; displayed power is relative and not calibrated dBm. No specific receiver's ADC scaling, channel tuning or timing is assumed. The parser does not guess interleaving, endianness or sample rate for binary files.

For a training dataset, prepare a manifest:

```csv
path,label,group,sample_rate
captures/a.csv,clean,session-01,2000000
captures/b.csv,narrowband,session-02,2000000
```

Run `scripts/extract_iq_features.py manifest.csv features.csv`. Recording paths resolve relative to the manifest. Each file is one feature row. Keep all windows from one original capture in the same group, even if their files have different names. The feature extractor computes power, crest factor, spectral entropy/flatness, peak power fraction, occupied bandwidth, envelope variation, phase-step variation, duty-cycle proxy, spectral centroid/spread, and envelope kurtosis.

Zenodo's raw-IQ archive needs format-specific decoding into I/Q first. Sentinel does not claim a universal parser for the original archive. The publisher states that its dataset includes no-jamming, DME, narrowband, AM, chirp and FM recordings. The platform's `pulsed` synthetic signal is a generic pulse-gated tone and must not be relabeled as equivalent DME benchmark data.

## Image training

```text
image-study/
  train/clean/*.png
  train/chirp/*.png
  val/clean/*.png
  val/chirp/*.png
  test/clean/*.png
  test/chirp/*.png
```

Every split needs identical class folders. Keep the publisher's test set untouched. Create validation data from the official training partition, grouping by original capture where metadata permits. Do not combine and reshuffle the publisher's training and test sets. Duplicate-content detection rejects identical image files crossing splits.

`train-images` records a content-hashed image manifest and saves the best validation checkpoint. Preprocessing is consistently RGB, 128×128, and ImageNet mean/std. `predict-image` restores the saved class names, calls evaluation mode and disables gradients.

## Synthetic fixtures

Receiver fixtures contain broad statistical patterns in thirteen feature columns, four descriptive classes and synthetic session IDs. They are not a physics-accurate spoofing simulator. IQ fixtures are noisy complex-baseband patterns across six classes and randomized SNR. Synthetic labels are generated by construction. High scores therefore cannot establish real-world generalization.

Preserve dataset licenses, citation requirements and capture consent. Dataset source links appear in `catalog.json` and the dashboard; downloaded public data is not included in the repository.
